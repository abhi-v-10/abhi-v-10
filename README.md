## About

I'm a third-year B.Tech Computer Science student in Hyderabad, studying at Chaitanya Deemed to be University in collaboration with NxtWave Institute of Advanced Technologies (NIAT). Backend is home for me: Python, Django, DRF and FastAPI, and more and more AI agents that call tools and return structured results.

- **Experience:** AI Backend Engineer Intern at **Nestafar Technologies** (Jan – Mar 2026). I built AI agents with Python, Django, FastAPI and FastMCP that read live backend data through internal APIs, and worked on a production Django hospitality platform: REST APIs, Celery tasks, Redis caching, and Linux-based debugging and deployment.
- **Campus:** Core Team Member of the NIAT Student General Council, 2024 – 2026.
- **Exploring now:** advanced AI agents · LLM app architecture · retrieval systems · Three.js & WebGL · cloud deployment (AWS, Azure) · DSA in C++.
- **In progress:** a 3D portfolio built with React, React Three Fiber and Three.js, around a core modelled in Blender. It's still private; my current live portfolio is [here](https://abhi-ai-portfolio.lovable.app/).
